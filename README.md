# 中州韵输入法离线安装包

适用系统：银河麒麟桌面操作系统 V10 SP1（ARM64，飞腾/鲲鹏芯片）
离线环境：完全离线，无需联网

## 内容
中州韵（RIME）输入法的 fcitx4 前端（fcitx-rime）+ 引擎（librime1）及输入方案，全部来自麒麟官方软件源，已逐个校验。

包含方案：
- 全拼（朙月拼音）
- 五笔86
- 五笔拼音混输
- 仓颉5

共 24 个安装包（.deb），压缩后约 17.7 MB。

## 安装步骤
1. 解压 rime-kylin-v10-arm64-offline.zip
2. 进入 debs 文件夹，右键「在终端中打开」
3. 执行：sudo dpkg -i *.deb
4. 注销重新登录
5. 右下角输入法托盘 → 配置 → 添加「Rime（中州韵）」→ 确定
6. Ctrl+空格 切换到中州韵

## 默认用五笔
把五笔配置/default.custom.yaml 复制到主目录 .config/fcitx/rime/ 下（.config 是隐藏文件夹，文件管理器按 Ctrl+H 显示），再在托盘输入法图标右键 → 重新部署。

## 说明
- 不影响系统原有搜狗输入法，两者可共存
- 安装若报缺少依赖，把报错发回补包
